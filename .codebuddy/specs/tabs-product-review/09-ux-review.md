- 统一交互模式规范（折叠、多选、拖拽）有代码示例，可直接指导开发

- **设计遗漏**: 未定义"深色模式"设计规范（当前设计系统只有浅色）

#### 改进建议
- `Collapsible` 持久化改为 `chrome.storage.local`（或 sync）
- 域名色哈希算法增加对比度验证，失败时 fallback 到安全色

## 3. 设计方案改进建议（具体到章节或组件）

### 3.1 `Collapsible` 组件（`05-ux-design.md` 2.1.1 节）

**问题**: 使用 `localStorage` 持久化，不符合 Chrome 扩展最佳实践。

**改进方案**:
```typescript
// 改为使用 chrome.storage.local
const [collapsed, setCollapsed] = useState(() => {
  if (persistKey) {
    // 异步读取，初始状态使用 defaultCollapsed
    chrome.storage.local.get(`collapse:${persistKey}`).then(result => {
      if (result[`collapse:${persistKey}`] !== undefined) {
        setCollapsed(result[`collapse:${persistKey}`]);
      }
    });
  }
  return defaultCollapsed ?? false;
});

const handleToggle = () => {
  const next = !collapsed;
  setCollapsed(next);
  if (persistKey) {
    chrome.storage.local.set({ [`collapse:${persistKey}`]: next });
  }
  onToggle?.(next);
};
```

**注意**: `chrome.storage.local` 是异步 API，需要处理初始状态的 loading 问题（可使用 `useSyncExternalStore` 或初始渲染使用 `defaultCollapsed`）。

### 3.2 域名色哈希算法（`05-ux-design.md` 1.2 节）

**问题**: HSL 生成的浅色背景可能对比度不足。

**改进方案**:
```typescript
function hashDomainColor(domain: string): string {
  let hash = 0;
  for (let i = 0; i < domain.length; i++) {
    const char = domain.charCodeAt(i);
    hash = ((hash << 5) - hash) + char;
    hash = hash & hash;
  }
  const hue = Math.abs(hash) % 360;
  
  // 确保对比度 >= 4.5:1（在白色文字下）
  // 使用 HSL 的 L(ightness) 控制在 92%-96% 之间
  const lightness = 94 + (Math.abs(hash) % 5); // 94%, 95%, 96%, 97%, 98%
  return `hsl(${hue}, 45%, ${lightness}%)`;
}
```

**验证工具**: 使用 WebAIM Contrast Checker 验证所有生成的颜色组合。
