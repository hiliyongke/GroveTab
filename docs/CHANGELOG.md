# Canopy 版本记录

本文档用于记录已发布版本与已确认的后续版本规划。

## [Unreleased]

### 2026-04-23 — UI / 交互友好性优化规划已确认

本次记录不包含功能代码变更，仅用于固化下一阶段的前端体验优化方向，便于后续分版本推进。

#### 目标

- 降低首页认知负担，让用户一打开就知道当前最适合做什么
- 缩短高频操作路径，让搜索、整理、归档、多选等动作更顺手
- 强化操作结果可感知性，让成功、失败、部分成功都更清晰
- 为后续会员版 UI 扩展预留清晰入口，但不打扰当前免费用户体验

#### 下一阶段版本拆分建议

##### v0.2.0 — 首页工作台与高频操作优化

- 新增首页摘要区，展示标签数、重复标签数、闲置标签数、窗口数、最近归档时间
- 将首页主操作前置为 3 个高频入口：搜索标签、整理重复/闲置、归档当前窗口
- 强化多选模式可见性：进入态提示、范围选择反馈、所选上下文说明
- 优化归档反馈：支持从成功提示直达对应会话，明确展示部分关闭失败情况
- 优化空状态与首次使用引导，让帮助信息出现在用户真正需要的时机

##### v0.3.0 — 搜索与上下文管理增强

- 将 `SearchBox` 从标签搜索升级为命令中心，支持搜索动作、会话、书签
- 空输入时展示推荐动作与最近操作，降低首次使用门槛
- 增加“恢复最近归档”快捷入口
- 为批量操作增加更清晰的预览与可撤销反馈
- 增加最近操作状态区，用于显示归档、恢复、导入、权限申请等结果

##### v0.4.0 — 面向会员版的体验预留

- 为高级搜索、跨设备同步、工作区、长期归档等能力预留 UI 扩展位
- 引入轻量功能 gating 设计，避免会员能力与免费能力在首页互相污染
- 支持更细的归档恢复方式，例如恢复到当前窗口、新窗口或部分恢复
- 支持按窗口、域名组、重复组进行更自然的整组操作

#### 实施优先级

1. 先做首页摘要、主操作收敛、多选可见化、归档反馈增强
2. 再做搜索命令中心、最近操作状态区、恢复最近归档
3. 最后补会员版入口与高级能力的 UI 扩展点

#### 设计原则

- 优先减少用户决策，而不是继续堆功能入口
- 优先强化搜索、归档、多选、整理四条主路径
- 优先保证结果可解释、可恢复、可追踪
- 会员能力采用渐进暴露，不提前制造界面噪音

## [0.1.0]

### 当前阶段基线

- 已具备标签管理、搜索、归档、书签、多视图、快捷键、多选等核心能力
- 已完成归档链路统一、初始化兜底、导入校验增强、批量操作优化等基础稳定性工作
- 后续体验优化应在现有稳定基线上继续推进
