## 域名分组搜索后布局无法还原修复（2026-05-27）

### 问题

域名分组模式搜索后清除搜索，masonry 多列布局变成单列平铺，无法还原。

### 根因

搜索无结果时 `containerRef` 绑定的 masonry div 被 `<Empty>` 组件替换，ResizeObserver 断开；
清除搜索后容器 div 重建，但 `useLayoutEffect` 依赖 `[forcedColumns, groups.length]` 没变化不重新执行，
ResizeObserver 未重新绑定 → `containerWidth` 过时 → 列数算错变 1 列。

### 修复

将 masonry 容器 div 改为始终渲染，`<Empty>` 放入容器内部作为子元素。
这样 ResizeObserver 始终能观测容器宽度变化，清除搜索后列数立即恢复。

### 文件

- 修改：`src/features/tabs/DomainGroupView.tsx`（容器 div 始终渲染，Empty 移入内部）

## 历史记录最近关闭列表样式修复（2026-05-27）

### 问题

历史记录面板"最近关闭"列表样式错乱——favicon 溢出、行高不齐、布局整体乱。

### 根因

- 使用 Ant Design `<Image>` 组件显示 favicon，但 Image 会生成 `.ant-image > .ant-image-img` 嵌套 DOM
- CSS 只设了外层 `.history-item-favicon` 18×18px，内层 img 无尺寸约束 → favicon 溢出容器
- `.history-item-favicon` 同时 `display: inline-flex` + `object-fit: contain`，后者对 flex 容器无效
- `onError` 里 `display: none` 使 ant-image 包裹层塌陷影响行高

### 修复

- 用原生 `<img>` 替换 Ant Design `<Image>`（favicon 不需要预览功能）
- 新增 `.history-item-favicon-wrap` 包裹容器，统一 18×18 尺寸
- `.history-item-favicon` 设为 16×16 + `object-fit: contain` + `display: block`
- favicon 加载失败时自动切换到 Globe icon fallback（img hidden → fallback visible）
- 移除未使用的 Image 导入

### 文件

- 修改：`src/features/history/HistoryPanel.tsx`（Image → img + fallback 逻辑）
- 修改：`src/features/history/HistoryPanel.module.less`（重构 favicon 样式）
