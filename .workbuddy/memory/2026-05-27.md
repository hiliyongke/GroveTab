## 产品功能架构审视（2026-05-27）

### 核心发现

1. **视图模式过度设计**：10 种视图模式（domain/compact/timeline/tabgroup/window/kanban/bookmarks/frequency/grid/archive），竞品仅 1-3 种
2. **目录分类混乱**：BookmarkTreeView/BookmarkView 放在 `features/tabs/` 下，与标签管理混淆
3. **页面模式偏离核心**：DeveloperToolsPage 和 TrendingPage 作为一级页面模式，与「标签管理器」定位偏离
4. **设置面板可合并**：BehaviorPanel 已内聚 5 个子面板，一级 Tab 可从 6 个合并为 4 个
5. **历史相关功能分散**：HistoryPanel/TimelineView/ArchiveView/TrashView 都与「过去」相关，但入口分散

### 建议整合方向

- 视图模式：10 → 5 核心（domain/window/timeline/tabgroup + 2 布局选项）
- 设置面板：6 Tab → 4 Tab（appearance/behavior/system/about）
- 书签视图：从 `features/tabs/` 移至 `features/bookmarks/views/`
- archive/bookmarks：从 ViewDock 移出，改为独立入口
- devtools/trending：从 page mode 降级为可选模块

## Phase 2 高优先级改进（2026-05-27）

### 1. 视图合并（domain/compact/grid → tabs + layout）

**问题**：ViewDock 9 种视图模式认知负担过重，domain/compact/grid 本质都是「标签页浏览」的不同布局。

**方案**：
- 合并为统一的 `tabs` 视图，内部通过 `settings.tabsLayout` 切换（masonry/compact/grid）
- 新建 `TabsView.tsx` 作为布局分发器
- ViewDock 选项从 8 减到 6（tabs/timeline/tabgroup/window/frequency/kanban）
- `archive` 保留为隐藏视图（order: 99）

**兼容**：
- `LEGACY_VIEW_MAP` 自动迁移旧设置（domain→tabs+masonry, compact→tabs+compact, grid→tabs+grid）
- `defaultView` 类型保留 legacy 值（"domain"/"compact"/"grid"）确保运行时兼容

**文件**：
- 新建：`src/features/tabs/TabsView.tsx`
- 修改：`src/shared/config/views.ts`, `src/pages/newtab/App.tsx`, `src/features/settings/panels/ViewLayoutSettings.tsx`
- i18n：`view.tabs` → "标签页"，`view.domain` → "瀑布流"（用于 layout 切换标签）

### 2. 目录迁移（Bookmark → features/bookmarks/）

**问题**：BookmarkTreeView/BookmarkView 放在 `features/tabs/` 下，与标签管理逻辑混淆。

**改动**：
- `src/features/tabs/BookmarkTreeView.tsx` → `src/features/bookmarks/BookmarkTreeView.tsx`
- `src/features/tabs/BookmarkView.tsx` → `src/features/bookmarks/BookmarkView.tsx`

- BookmarkView 的 `views.module.less` import 改为 `@/features/tabs/styles/views.module.less`

### 3. Onboarding 更新

**改动**：
- Tour 步骤从 3 步扩展到 4 步
- 第 1 步（工作台总览）：加入 Cmd+K 全局搜索说明
- 第 2 步（归档与回收站）：覆盖回收站功能

- 第 4 步（快捷键帮助）：更新文案，指向 设置→行为

### 4. 标签页使用时长追踪

**设计**：
- SW 中监听 `chrome.tabs.onActivated` / `onRemoved`，记录每个标签页的聚焦时长
- 按 URL × day 聚合，保留 30 天
- 内存缓存 + 30s flush 到 `chrome.storage.local`
- 使用 `chrome.storage.session` 保存当前激活会话（MV3 SW 挂起后保留）

**UI**：
- 新建 `useFocusTime(url)` hook，监听 storage 变化
- TabItem 标题 Tooltip 展示：`{title} · 今日 12m`

**设置**：
- `trackTabFocusTime?: boolean`（默认 true）
- 开关位于 设置 → 行为 → 通用行为

**文件**：
- 新建：`src/shared/types/focus-time.ts`, `src/repositories/focus-time-repo.ts`, `src/shared/hooks/use-focus-time.ts`
- 修改：`src/sw/index.ts`（FocusTimeTracker）, `src/features/tabs/TabItem.tsx`, `src/features/settings/panels/GeneralSettings.tsx`
